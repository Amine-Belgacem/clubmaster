# Clubmaster

Clubmaster is a FileMaker database project for club administration. It provides an existing database and layouts to inspect and adapt, rather than a separate web application and server stack to install.

It is useful as a starting point for a club workflow built in FileMaker, or for studying how an existing FileMaker project is organized before customizing it. Make a working copy, review its records and structure in a compatible FileMaker installation, and adapt the layouts and workflow to your club's requirements.

## Get started

1. Install a compatible version of FileMaker Pro / Claris FileMaker.
2. Make a working copy of [clubmaster.fmp12](clubmaster.fmp12).
3. Open the copy in FileMaker and review the database structure before customizing it.

The repository contains the FileMaker database. This is a database project, not a standalone application installer.
